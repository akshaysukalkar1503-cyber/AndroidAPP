# ऊस मित्र AI — Android ऑफलाइन MVP

मराठी Android अ‍ॅपचा प्रारंभिक प्रकल्प. इंटरनेटशिवाय स्थानिक स्क्रीन व मूलभूत सुविधा चालण्यासाठी बनवलेला.

## सध्या समाविष्ट
- मराठी होम स्क्रीन
- गाव, जिल्हा, क्षेत्र, जमीन, पाणी स्रोत आणि पिकाची अवस्था जतन करणे
- प्राथमिक नियमाधारित पाणी व्यवस्थापन सूचना
- खर्च, अपेक्षित उत्पादन, दर आणि अंदाजित नफा कॅल्क्युलेटर
- स्थानिक शेत नोंदवही
- इंटरनेट permission नाही; माहिती फोनवरच SharedPreferences मध्ये साठवली जाते

## अद्याप समाविष्ट नाही
- प्रशिक्षित AI रोग निदान मॉडेल
- थेट हवामान/पाऊस डेटा
- प्रमाणित खत मात्रा किंवा स्वयंचलित सिंचन वेळापत्रक
- क्लाउड बॅकअप/सिंक
- औपचारिक कृषी तज्ज्ञांकडून पडताळणी

## Android Studio मध्ये चालवा
1. ZIP extract करा.
2. Android Studio मध्ये `OosMitraAI` फोल्डर उघडा.
3. Gradle sync पूर्ण होऊ द्या. आवश्यक Android SDK 35 आणि JDK 17 उपलब्ध असू द्या.
4. Android फोनवर Developer options आणि USB debugging चालू करून फोन जोडा, किंवा emulator वापरा.
5. Run दाबा.

Android Studio आवश्यक dependencies डाउनलोड करण्यासाठी पहिल्या build वेळी इंटरनेट लागू शकते. एकदा build झाल्यावर अ‍ॅपची मुख्य सुविधा ऑफलाइन चालते.

## महत्त्वाची कृषी सूचना
पाणी व्यवस्थापनातील सूचना साध्या नियमांवर आधारित आहेत; मातीतील ओलावा सेन्सर किंवा हवामान API वापरलेले नाही. खत/फवारणीसाठी अ‍ॅपचा हा नमुना अंतिम कृषी सल्ला समजू नये. स्थानिक कृषी विद्यापीठ/कृषी अधिकारी यांच्याकडील अद्ययावत शिफारशींचा वापर करा.

## पुढील टप्पे
- Room database migration व backup/export
- PDKV/ICAR कडून परवानगीयोग्य, अद्ययावत कृषी मार्गदर्शक पॅक
- IMD हवामान डेटा डाउनलोड व freshness timestamp
- TensorFlow Lite/LiteRT मॉडेल, प्रत्यक्ष क्षेत्रीय validation
- Accessibility, मोठा मजकूर, voice input/readout, Android version testing
